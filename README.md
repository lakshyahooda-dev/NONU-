## About the Project

**NONU** is a desktop AI assistant project developed by **Lakshya Hooda**. It combines a graphical desktop interface with voice-oriented interaction to explore a more accessible and conversational assistant experience.

The project focuses on bringing together Python application development, user-interface design, voice interaction, and integrations in one desktop application.

## Key Features

- **Desktop AI Interface** — A dedicated graphical interface designed for interacting with the assistant.
- **Voice Interaction** — Voice-oriented input and spoken responses, depending on the configured services and available devices.
- **Hindi and English Interaction** — Intended to support a more natural multilingual experience.
- **Animated Visual Experience** — An animated, futuristic interface with assistant status feedback.
- **System and Audio Controls** — Interface options for supported microphone, audio, and assistant settings.
- **Extensible Architecture** — A foundation for integrating additional assistant actions and capabilities.
- **Configurable Integrations** — External AI services and related settings can depend on local configuration and API credentials.

> Feature availability may depend on the selected provider, API configuration, installed dependencies, and connected hardware.

## Technology Stack

The project is built around Python and a desktop application architecture. The exact technologies and integrations depend on the current source code and configuration.

- **Language:** Python
- **Application:** Desktop AI assistant
- **Interface:** PyQt6-based UI, where used by the application
- **AI and Voice:** Configurable AI/voice integrations
- **Development Tools:** Git, GitHub, and Python virtual environments
